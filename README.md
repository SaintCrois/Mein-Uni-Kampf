# TokTickIT 

SETUP

1. Copy `.env.example` to `.env` (if applicable).

Interminal run the following command (make sure your file path is XXX/toktickit):

2. cd client (XXX/toktickit/client), npm install (only for first time)
3. cd server (XXX/toktickit/server), npm install (only for first time)
4. cd server, npm run dev
5. cd client, npm run dev
